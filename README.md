# Orrery (오러리)

<img src="public/orrery.svg" width="64" alt="">


Orca에 열려 있는 세션을 탭을 오가지 않고 **한 화면에서** 보고, 답하고, 선택지를 고르는 앱이에요. 앱은 별, 터미널은 행성이 되어 은하 안에서 돌아가요. 이름은 행성들이 태양 주위를 도는 모습을 보여주는 태엽 태양계 모형(orrery)에서 따왔어요. 예전 이름은 Orca Portal이에요.

## 설치와 실행

필요한 것은 두 가지예요. Orca 앱이 켜져 있어야 하고, Node 20 이상이 있어야 해요. 설치할 패키지는 없어요.

```bash
npx github:ghkim/orcaportal
```

이 한 줄로 받기, 서버 켜기, Orca 내장 브라우저에 오러리 탭 열기까지 끝나요. 서버만 켜려면 끝에 `--no-open`을 붙이고 `http://127.0.0.1:4870/`을 직접 열면 돼요.

코드를 받아서 쓰려면 이렇게 해요.

```bash
git clone https://github.com/ghkim/orcaportal.git && cd orcaportal
npm run portal   # 서버를 켜고 Orca 내장 브라우저에 오러리 탭을 열어요
npm start        # 서버만 켜요
```

포트가 사용 중이면 다음 빈 포트를 써요. `PORT=5000 npm start`처럼 포트를 직접 정할 수도 있어요. macOS에서 확인했어요. Windows와 Linux 경로도 코드에는 있지만 아직 돌려보지 않았어요.

### Mac 앱

오러리를 창 하나짜리 Mac 앱으로도 쓸 수 있어요. 서버와 은하가 앱 안에 같이 들어 있어서 Node가 없어도 돼요.

```bash
npm install
npm run app    # 코드에서 바로 앱으로 띄워요
npm run dist   # release/에 Apple Silicon용과 Intel용 .dmg를 만들어요
```

- 터미널에서 켠 오러리 서버가 4870에 이미 있으면 그걸 그대로 써요. 서버가 둘이면 Orca를 두 번 읽고 소리도 두 번 나서예요. 없으면 앱이 직접 켜요.
- Dock 아이콘에 확인이 필요한 세션 수가 배지로 떠요.
- 창이 뒤에 있을 때 질문이 오면 macOS 알림이 와요. 누르면 그 행성으로 가요. 알림은 소리 없이 오고, 소리는 오러리의 종이 내요.
- 창을 닫아도 앱은 Dock에 남고 서버는 쉬어요. 창이 다른 창에 가려져도 우주 소리는 계속 나요.
- 링크(PR, 개발 서버)는 기본 브라우저에서 열려요.
- 앱의 설정, 도감, 별가루는 브라우저와 따로 저장돼요.
- 아직 Apple 개발자 서명이 없어요. 내려받은 `.dmg`의 앱은 처음 열 때 막히니, 시스템 설정 → 개인정보 보호 및 보안에서 '그래도 열기'를 눌러 주세요. 배포 전에 Developer ID 서명과 공증을 붙일 거예요.
- 점검용: `ORRERY_SMOKE=/tmp/shot.png npm run app`은 소리 없이 열어 화면을 저장하고 닫아요.

### Orca와 연결되는 방식

따로 설정할 것은 없어요. Orca는 켜질 때 `~/Library/Application Support/orca/orca-runtime.json`에 로컬 소켓 주소와 접속 토큰을 적어 둬요. 오러리는 요청할 때마다 이 파일을 읽고, 그 소켓에 토큰과 요청을 JSON 한 줄로 보내요(`worktree.ps`, `terminal.list`, `terminal.read`). `orca` CLI가 Orca에 붙는 방식과 같아요. Orca를 다시 켜면 새 주소와 토큰으로 저절로 다시 붙어요. 입력 보내기와 탭 열기는 `orca` CLI로 해요. CLI가 PATH에 없으면 `/Applications/Orca.app` 안의 것을 써요. 위치가 다르면 `ORCA_USER_DATA_PATH`, `ORCA_CLI_COMMAND` 환경변수로 알려주세요.

## 화면

- **은하 보기 (기본)**: 3D 은하 위에 모든 세션을 띄워요. 앱(프로젝트) 하나가 항성 하나이고, 그 앱의 터미널들이 행성으로 항성을 돌아요. 행성 테두리 빛이 상태를 알려줘요(주황은 확인 필요, 파랑은 작업 중, 초록은 새 결과). 작업 중인 행성은 더 빠르게 공전하고, 확인이 필요한 행성에서는 신호 고리가 퍼져요. 끌어서 돌리고 휠로 확대해요. 빈 곳을 더블클릭하거나 `V`를 누르면 전체 은하로 돌아와요. three.js(r186, MIT)는 `public/vendor/three`에 들어 있어서 인터넷 없이도 돼요.
  - **배경**: 하늘에는 보라, 청록, 장밋빛 성운이 깔려 있고, 은하수가 가운데 어두운 먼지 띠를 품은 채 하늘을 가로질러요. 은하수의 중심 쪽은 따뜻한 금빛이에요. 먼 곳에는 작은 은하들과 고리 모양 행성상 성운이 떠 있고, 빛줄기가 달린 밝은 별들이 반짝여요. 나선팔을 따라 분홍빛 별 탄생 구름과 푸른 젊은 성단이 빛나고, 팔 안쪽의 검은 먼지 띠는 한 줄로 고르게 깔리지 않고 덩어리와 틈, 팔 사이로 뻗는 깃털 같은 갈래로 흩어져 있어요. 옆에서 보면 은하도 두께가 있어요: 가운데 팽대부가 둥글게 부풀어 있고, 오래된 별들이 두꺼운 원반과 위아래를 감싸는 헤일로를 이루며, 바깥 원반은 모자 챙처럼 한쪽은 위로 한쪽은 아래로 휘어요. 먼지는 옆에서 볼수록 가늘고 옅어져서, 수평으로 보면 원반 가운데를 지나는 얇은 검은 띠가 돼요. 은하 위아래에는 금빛 구상성단이 떠 있어요. 가까이 날아가면 구름이 옅어져 시야를 가리지 않아요. 별똥별은 10~30초마다 떨어지고, 몇 분에 한 번은 여러 개가 한꺼번에 쏟아지는 유성우가 와요. 꼬리 달린 혜성이 1~2분에 걸쳐 먼 하늘을 천천히 가로지르기도 해요.
  - **항성의 모양**: 색은 프로젝트의 나이예요. 새 프로젝트는 푸르고, 오래될수록 흰색, 노랑, 주황을 지나 붉어져요. 크기는 그 앱에서 에이전트가 쓴 토큰과 일한 시간으로 정해져요. 같은 앱의 워크트리가 여러 개면 동반성이 함께 돌아요. 오래된 항성에는 흑점이 생기고, 항성마다 빛줄기 모양과 회전이 조금씩 달라요. 항성은 나선팔을 따라 고르게 흩어져요. 새 항성은 자기 몫의 후보 자리 16곳 가운데 다른 항성과 가장 먼 곳에 자리 잡고, 그 자리를 이 브라우저에 기억해요. 그래서 다른 앱이 생기거나 사라져도 움직이지 않아요. 은하 원반은 두꺼워서 항성이 위아래로도 흩어져 있어요. 중심 쪽이 두껍고 가장자리로 갈수록 얇아져요. 별 위에 마우스를 올리면 그 앱이 쓴 토큰과 일한 시간이 보여요.
  - **행성 주변**: 서브에이전트가 일하면 그 행성 둘레에 작은 위성(🌙)이 돌아요. 워크트리에 연결된 PR이 있으면 인공위성(🛰)이 떠서 PR 상태와 체크 결과를 불빛 색으로 보여줘요. 워크트리 안에서 서버가 켜지면(개발 서버, 미리보기, 로컬 API 등) 작은 탐사선(📡)이 행성 표면에서 솟아올라 궤도를 돌고, 서버가 꺼지면 다시 행성으로 떨어져 사라져요. 몇 초마다 `lsof`로 확인하고, Claude나 Codex가 자체로 여는 포트는 세지 않아요. 행성 위에 마우스를 올리거나 리포트를 열면 서버 이름과 포트가 보이고, 포트를 누르면 그 주소가 열려요.
  - **항성 리포트**: 항성이나 행성을 누르면 카메라가 그 항성계로 날아가고, 오른쪽 위에 짧은 보고가 떠요. 내가 골라야 할 선택지와 답이 필요한 질문이 먼저 나오고, 그 아래 작업 중인 것과 끝난 것을 한두 줄로 보여줘요. 선택지는 거기서 바로 고르고, 줄마다 있는 입력칸으로 답이나 다음 명령을 바로 보낼 수 있어요. 터미널 화면 전체는 `자세히 ›`를 누르거나 줄을 더블클릭할 때만 오른쪽 패널에 열려요. 패널은 오른쪽 끝의 손잡이로도 열고 닫아요.
  - **워프**: 다른 앱으로 갈 때는 지금 항성에서 목적지 항성까지 별빛 줄기 사이를 날아가요. 화면 위에 목적지 이름과 진행 막대가 떠요. 도착하면 그 항성에서 빛이 터지며 충격파 고리가 퍼져요. 같은 항성계 안에서는 미끄러지듯 옮겨 가요.
  - **탄생**: 새 앱의 첫 터미널이 열리면 가스 구름이 모여 돌다가 빛과 함께 항성이 켜져요. 새 터미널은 먼지 고리가 모여 행성이 돼요.
  - **소멸**: 터미널을 닫으면 그 행성은 테두리가 한 번 밝게 타오른 뒤 작아지고, 작은 불꽃을 남기며 사라져요. 앱의 마지막 터미널까지 닫으면 그 항성이 죽어요. 붉은 거성으로 부풀어 행성들을 삼키고, 백색 왜성으로 쪼그라든 다음 빛과 함께 터져요. 푸른 성운이 잠시 남았다가 사라져요.
  - **혜성과 별똥별**: 오러리에서 답이나 선택을 보내면 혜성이 그 행성으로 날아가요. 작업이 끝나면 먼 하늘에 별똥별이 지나가요.
  - **마젤란 구름**: 은하 가장자리 너머에 작은 위성 은하 두 개가 떠 있어요. 큰 쪽은 막대 모양 중심과 분홍빛 타란툴라 성운을, 작은 쪽은 라벤더빛 구름을 품고, 둘 사이를 옅은 별 다리가 이어요. 은하 원반 밖에 있어서 은하가 도는 동안 천천히 둘레를 도는 것처럼 보이고, 카메라가 반대편에 있을 때 먼 가장자리 위로 보여요.
  - **원시행성 원반**: 태어난 지 일주일이 안 된 항성 둘레에 먼지 원반이 돌아요. 행성 궤도마다 틈이 파여 있고, 안쪽은 따뜻한 살구빛, 바깥은 라벤더빛이에요. 사흘쯤까지는 또렷하고 일주일에 걸쳐 옅어져요.
  - **은하 중심의 숨**: 은하 중심이 8초쯤마다 천천히 숨을 쉬어요. 들숨이 날숨보다 조금 빠르고, 뜨거운 심장에서 보랏빛 헤일로까지 숨이 바깥으로 번져요. 여섯 번에 한 번은 깊게 쉬고, 일하는 에이전트가 많으면 조금 빨라져요.
  - **초신성 잔해**: 앱의 마지막 터미널을 닫아 항성이 터진 자리에는 분홍과 청록 실타래 같은 가스 껍질이 남아요. 가운데에서는 펄서가 깜빡여요. 20초에 걸쳐 피어나 사흘 동안 천천히 넓어지며 옅어지고, 최근 8개까지만 남아요. 이 브라우저에 기억돼요.
  - **은하 중심 제트**: 일하는 에이전트가 있으면 은하 중심 위아래로 가는 빛줄기가 뿜어져 나와요. 일하는 에이전트가 많을수록 길고 밝아지고, 다들 쉬면 천천히 사그라들어요.
  - **별의 왕관**: 앱이 쓴 토큰이 1천만, 5천만, 1억, 5억, 10억을 넘을 때마다 그 별 위에 작은 빛이 하나씩 늘어 왕관처럼 돌아요. 보고 있는 동안 넘으면 별 둘레에 파스텔 불꽃이 터지고 별가루를 하나 받아요.
  - **혜성 던지기**: `Alt`를 누른 채 끌거나, 빈 곳을 꾹 누른 채 끌었다 놓으면 새총처럼 혜성이 날아가요. 별과 은하 중심이 끌어당겨 길이 휘고, 끄는 동안 휘는 길이 미리 보여요. 화면에서 어떤 별이나 행성을 겨냥하면 그 깊이까지 날아가고, 중력으로 휘는 만큼 미리 고쳐 잡아서 실제로 맞아요. 맞을 곳에는 고리가 표시돼요. 혜성에 맞은 행성은 살짝 밀려 흔들리고, 혜성 색의 빛무리가 몇 분 동안 남아요. 같은 행성을 세 번 맞히면 그 색의 먼지 고리가 생겨요. 혜성마다 색이 달라요. 머리와 꼬리가 서로 다른 파스텔색이고, 가끔 무지개 꼬리가 나와요. 끄는 세기는 화면 위 거리로 재서, 비스듬히 볼 때도 방향에 따라 세기가 달라지지 않아요.
  - **고요 모드**: `Z`를 누르거나 3분 동안 아무것도 하지 않으면 글자와 패널이 사라지고 은하와 소리만 남아요. 마우스를 움직이거나 키를 누르면 돌아와요. 확인이 필요한 세션이 생겨도 깨어나요.
  - **유람 모드**: 고요 모드가 켜지면 카메라가 혼자 은하를 둘러봐요. 워프 없이 별로 천천히 날아가 20~30초쯤 그 둘레를 돌고, 최근에 안 본 다른 별로 넘어가요. 원반을 낮게 스치거나, 옆에서 보거나, 높이서 내려다보는 식으로 별마다 높이가 달라요. 네 번에 한 번은 크게 물러나 은하 전체를 낮은 각도로 보여줘요. 음악은 지금 보는 별의 음계를 따라가요. 무엇이든 건드리면 그 자리에서 멈추고, 질문이 생기면 깨어나서 자동 이동이 그 행성으로 데려가요. 설정(`S`)의 빛에서 끌 수 있고, 끄면 고요 모드는 카메라를 보던 곳에 그대로 둬요.
  - **찾기**: 위쪽 찾기 칸에 글자를 넣으면 은하 전체가 보이도록 물러나고, 찾은 행성마다 차례로 불이 켜져요. 따뜻한 빛기둥이 서고 이름표가 금빛으로 바뀌며, 나머지는 어둡게 가라앉아요. 찾기 칸 오른쪽에 찾은 개수가 나와요. Enter를 누르면 가장 잘 맞는 행성으로 날아가고, 다시 누르면 다음 행성으로 가요(Shift+Enter는 이전). 다음에 갈 행성에는 `Enter ↵` 표시와 퍼지는 고리가 붙어요. 세션 제목이나 워크트리 이름이 맞는 것이 먼저, 앱 이름, 그 밖의 내용(마지막 요청, 답변, 화면) 순이에요. 낱말은 순서와 상관없이 모두 들어 있으면 찾고(`다중 포탈`), 띄어쓰기는 따지지 않아요(`포탈모드`). 이름은 초성으로도 찾아요(`ㅁㄹ` → 메모리).
  - 시스템에서 '동작 줄이기'를 켜 두면 효과 없이 바로 옮겨 가요.
- **다른 보기**: 위쪽 버튼은 없애고, `G`로 목록 → 은하 → 격자를 오가요.
- **목록 보기**: 왼쪽에 모든 세션이 한 줄 요약으로 모여요. 순서는 확인 필요, 작업 중, 새 결과, 완료, 셸이에요. 완료와 셸은 처음에 접혀 있어요. 오른쪽에는 고른 세션 하나가 크게 나와요(터미널 화면, 선택지, 답장 칸, 마지막 답변). `F`를 누르면 오른쪽 화면을 창 전체로 키워요.
- **격자 보기**: 모든 세션의 터미널 화면을 카드로 한꺼번에 봐요. 확인이 필요한 세션은 맨 위 칸에 선택지 버튼과 함께 모여요.

## 단축키

`?`를 누르거나 위쪽 `단축키` 버튼을 누르면 목록이 나와요. 목록에는 우주를 둘러보고 노는 키만 보여요.

| 키 | 하는 일 |
| --- | --- |
| `J`, `K` | 다음 / 이전 행성 |
| `N` | 신호를 보내는 행성으로 (차례로 돌아요) |
| `B` | 바로 전에 보던 행성 |
| `/` | 찾기: 세션 제목, 앱, 화면 내용으로 찾고 Enter로 그 행성까지 날아가요 |
| `↑` `↓` | 선택지가 떠 있으면 고르기, `Enter`로 확정. 선택지가 없으면 다음 / 이전 행성 |
| `V` | 은하 전체 보기 (패널과 리포트도 닫아요) |
| `T` | 별과 행성 이름을 모두 끄고 켜요. 꺼도 행성에 마우스를 올리면 이름이 나와요. 브라우저에 기억돼요 |
| `Z` | 고요 모드: 은하와 소리만 남겨요 |
| `C` | 새 별 만들기: 새 프로젝트를 시작해요 |
| `L` | 우주 도감 |
| `I` | 보는 법: 항성과 행성의 모양, 마우스로 할 수 있는 일 |
| `M` | 소리 켜기 / 끄기 |
| `S` | 빛과 소리 설정: 빛 번짐, 밝기, 소리 종류별 크기 |
| `Esc` | 열린 창 닫기 |

목록에 없는 예전 작업용 키(`Enter`/`R` 답장 칸, `1`–`9` 선택지, `F` 최대화, `G` 보기 바꾸기, `A` 자동 이동, `P` 고정, `O` Orca에서 열기)도 그대로 돼요.

답장 칸에 글을 쓰는 동안에는 단축키가 꺼져요. 글자 키는 물리 키 위치로 알아보기 때문에 한글 입력 상태에서도 돼요.

## 소리

위쪽 스피커 버튼이나 `M`으로 켜고 꺼요. 브라우저 정책상 페이지를 한 번 클릭하거나 키를 누른 뒤부터 소리가 나요. 소리 파일 없이 Web Audio로 직접 만들어요.

오러리를 여러 곳에 열어 두면(Orca 탭과 크롬 창 등) 소리는 한 곳에서만 나요. 마지막으로 누른 창에서 나고, 화면에 떠 있는 창이 먼저예요. 다른 창이 소리를 내는 동안에는 스피커 버튼이 흐려져요. 소리 설정은 브라우저마다 따로 기억돼요.

소리는 파도, 바람, 대나무 숲, 풍경, 범종, 싱잉볼과 은은한 음악을 써요. 아침엔 새, 밤엔 풀벌레, 가끔 돌확에 물방울이 떨어져요.

- **은하 보기에서 들리는 소리**: 바닷가 절이에요. 아래에서 파도가 쏴아 하고 밀려왔다 빠지고, 가끔 큰 파도가 와요. 바람이 불 때면 처마 끝 풍경이 울려요. 2~4분마다 범종이 멀리서 은은하게 울려요. 낮게 웅웅거리는 소리는 넣지 않았어요. 그 위로 유리 같은 음 일곱 개가 각자 다른 간격(20~48초)으로 천천히 울려요. 간격이 서로 맞지 않아서 같은 흐름이 거의 다시 나오지 않아요. 은하 전체를 볼 때 음은 모두 G단조 5음계이고, 풍경과 싱잉볼도 같은 음계에 맞춰 두어서 서로 부딪히지 않아요. 별에 가면 그 별의 음계로 바뀌어요(아래). 다른 보기로 가거나 탭이 가려지면 조용해져요.
- **상태 따라 변하는 음악**: 음악이 세션 상태를 따라 천천히 물들어요. 알림이 아니라 분위기만 바뀌어요.
  - 확인이 필요한 세션이 있으면 D에서 C로 내려와 걸린 채 끝나는 열린 음이 10초쯤마다 작게 울려요. 몇 분이 지나면 더 옅고 드물어져요. 답하면 B♭으로 내려앉고, 남은 질문이 없으면 G까지 내려가 풀려요.
  - 일하는 에이전트가 많을수록 음이 더 자주 울리고, 가끔 고운 음이 올라가는 짧은 아르페지오가 깔려요. 다들 쉬면 음 사이가 길어져요.
  - 카메라가 따라가는 별의 음색을 닮아요. 젊은 푸른 별이면 밝고 가끔 한 옥타브 위로, 오래된 붉은 별이면 따뜻하고 둥글게 가끔 한 옥타브 아래로 울려요. 그 별에서 에이전트가 일하면 잔잔하게 떨려요.
  - **별마다 자기 음계가 있어요.** 으뜸음 G는 그대로 두고 음계만 바뀌어서, 별을 옮겨 다녀도 소리가 부딪히지 않아요. 젊은 푸른 별일수록 밝은 쪽, 오래된 붉은 별일수록 어두운 쪽이고, 같은 나이의 별끼리도 한 칸씩 달라요. 같은 별은 언제 가도 같은 음계예요.
    - 리디안(G B C♯ D F♯): 떠 있는 듯한
    - 장조(G A B D E): 맑고 밝은
    - 서스(G A C D F): 밝지도 어둡지도 않은
    - 도리안(G A B♭ D E): 단조인데 살짝 들뜬
    - 단조(G B♭ C D F): 은하 전체를 볼 때의 기본 음계
    - 미야코부시(G A♭ C D E♭): 고요하고 먼
  - 별의 색에 따라 음색도 달라요. 젊은 별은 배음이 살아 유리처럼 맑게, 오래된 별은 배음이 줄어 둥글고 천천히 울려요.
  - 토큰을 많이 쓴 큰 별일수록 음이 조금 더 자주 울려요.
  - 물방울과 처마 풍경도 그 별의 음계를 따라가요. 다른 별로 가면 울리던 음이 사라지는 몇 초 사이에 새 음계로 넘어가고, 전체 보기(`V`)로 나오면 기본 음계로 돌아와요.
  - 알림 소리(질문의 D→C, 싱잉볼, 풍경 알림)는 어느 별에서든 그대로예요. 귀로 바로 알아들을 수 있게요.
  - 별마다 자기 음이 있어요(젊을수록 높게). 워프로 도착하면 싱잉볼과 유리 음이 그 별의 음계 안에서 그 별의 음으로 울려요.
  - 빛과 소리 설정(`S`)의 '음악이 상태 따라 변하기'로 끌 수 있어요.
- **대나무 숲**: 바람이 숨 쉬듯 몇 초마다 대숲을 기울이면 얇은 잎들이 사르르 흩날려요. 바람이 세게 불면 줄기끼리 부딪혀 '따각따각' 마른 소리가 나요. 빛과 소리 설정(`S`)에서 따로 크기를 맞춰요.
- **알림 소리**: 어느 보기에서든 울려요. 세션이 질문을 띄우면 싱잉볼이 한 번 울리고, 작업이 끝나면 풍경이 한 번 울려요.
- **워프 소리**: 바람이 높아졌다가 가라앉고, 도착하면 싱잉볼이 한 번 울려요.
- **활공 소리**: 워프 없이 가까운 별로 옮겨 가거나 전체 보기(`V`)로 물러날 때, 아주 작은 공기 소리가 카메라가 움직이는 쪽으로 지나가요.
- **별가루 소리**: 별가루가 생기면 맑은 음 두 개, 장식이 열리면 싱잉볼과 올라가는 유리 음, 앱이 이정표를 넘으면 올라가는 음과 풍경, 불꽃놀이는 낮은 퐁 소리와 높은 반짝임이에요.
- **별이 모이는 음악**: 새 별을 만드는 동안(깃 저장소를 받는 동안도) 그 별만의 음악이 따로 흘러요. 낮게 열린 화음(G·D·A·D)이 성운의 숨소리와 함께 부풀고, 일이 진행될수록 소리가 점점 밝게 열려요. 그 위로 먼지가 떨어지듯 작은 음이 반짝이는데, 진행될수록 더 자주, 더 높이 떨어지고, 가끔 세 음이 함께 올라가요. 그동안 평소 음악은 한발 물러나요. 별이 켜지면 화음이 활짝 열리며 올라가는 음과 함께 사라지고, 만들기에 실패하면 단3도 아래로 가라앉으며 사라져요. 크기는 음악 슬라이더를 따라요.
- **탄생과 소멸**: 행성이 생길 때는 풍경이 두 번 올라가며 울리고, 항성이 켜질 때는 따뜻한 싱잉볼과 풍경이 울려요. 행성이 사라질 때는 높고 여린 풍경 소리가 나고, 항성이 터질 때는 낮은 싱잉볼 뒤로 풍경 소리가 따라와요. 혜성이 닿을 때는 아주 작은 풍경 소리가 나요.

## 별가루와 장식 열기

처음부터 화려하지 않게, 우주는 쓰면서 조금씩 채워져요.

- **함께 쓴 토큰**: 이 브라우저가 세기 시작한 뒤로 에이전트가 쓴 토큰이에요. 그전에 쓴 양은 세지 않고, 세기 시작한 뒤에 생긴 워크트리는 처음부터 다 세요. 브라우저마다 따로 기억해요.
- **별가루**: 함께 쓴 토큰 1천만마다 하나씩 쌓이고, 앱이 토큰 이정표를 넘을 때도 하나 받아요. 우주 도감(`L`) 맨 위에서 써요.
  - 🌠 유성우 ✦1: 별똥별 열여섯 개가 한꺼번에 쏟아져요.
  - 🌌 오로라 2분 ✦2: 은하 둘레에 오로라가 2분 동안 켜져요.
  - ☄️ 혜성 떼 ✦2: 파스텔 혜성 여섯 개가 옆에서 날아와 화면 속 행성들을 찾아가요. 도감 기록에는 들어가지 않아요.
  - 🎆 초신성 불꽃놀이 ✦3: 먼 하늘에서 파스텔 초신성 일곱 개가 차례로 터져요.
- **장식 열기**: 장식은 조건을 채우면 열려요. 열릴 때 알림, 싱잉볼과 유리 음, 유성우가 함께 와요. 도감에서 다음 장식까지 얼마나 남았는지 보여요.
  - 원시행성 원반: 도감에서 별의 탄생 보기
  - 초신성 잔해: 도감에서 초신성 세 번 보기
  - 마젤란 구름: 함께 쓴 토큰 3천만
  - 별의 왕관: 함께 쓴 토큰 6천만
  - 은하 중심 제트: 함께 쓴 토큰 1억
  - 이 기능 전부터 오러리를 쓰던 브라우저는 그때 있던 장식(마젤란 구름, 원시행성 원반, 초신성 잔해, 은하 중심 제트)이 그대로 열려 있어요.

## 관리자 테스트

주소 끝에 `?admin`을 붙여 열면(`http://127.0.0.1:4870/?admin`) 빛과 소리 설정(`S`) 맨 아래에 '관리자 테스트' 칸이 생겨요. 이 브라우저에 기억되고, `?admin=0`으로 열면 꺼져요.

- 가짜 별과 행성을 만들어 탄생, 소멸, 작업 중, 질문, 답을 차례로 볼 수 있어요. 유성우, 먼 초신성, 먼 별 탄생을 바로 부르고, 초신성 잔해를 하루씩 지나가게 할 수도 있어요.
- 별가루와 장식 열기: 토큰 +1천만, 별가루 +5, 기념 불꽃(보고 있는 별), 장식 모두 열기, 해금 처음부터(새 우주처럼 다시 잠가요. 도감 조건을 이미 채운 장식은 다음 토큰이나 놀이 때 다시 열려요).
- `🪐 행성 하나 추가`는 마지막으로 본 테스트 별에 행성을 하나씩 붙여요. 테스트 별을 본 적이 없으면 가장 새 테스트 별에 붙여요.
- 가짜 별과 행성은 화면에만 있어요. 진짜 터미널을 만들거나 닫지 않고 아무 입력도 보내지 않아요. 이 브라우저에 기억돼서 새로고침해도 남아 있고, `🧹 테스트 별 치우기`로 한꺼번에 치워요.

## 고정

카드 위쪽 핀 버튼이나 `P`로 세션을 고정해요. 고정한 세션은 다음처럼 먼저 챙겨요.

- 목록 보기에서는 맨 위 '고정' 칸에 모여요.
- 격자 보기에서는 앞쪽에 와요.
- 은하 보기에서는 은하 중심 가까이에 놓이고, 이름 앞에 ★이 붙어요.
- 자동 이동과 `N`도 고정한 세션의 질문을 먼저 보여줘요.

고정은 워크트리 경로로 기억해서 Orca를 다시 켜도 그대로 남아요. 이 브라우저에만 저장돼요.

## 자동 이동

`자동 이동`이 켜져 있으면 일이 생긴 세션으로 오른쪽 화면이 저절로 바뀌어요.

은하 보기는 처음에 은하 전체를 보여주며 열려요. 자동 이동이 켜져 있고 기다리는 질문이 있을 때만 그 세션으로 날아가요.

- 질문이나 권한 요청이 새로 뜨면 그 세션으로 가요.
- 작업이 끝나면 그 세션으로 가요. 다만 지금 보고 있는 세션에 답하지 않은 질문이 있으면 옮기지 않아요.
- 답을 보내고 나면 다음으로 확인할 세션으로 넘어가요.
- 답장을 쓰는 중이거나, 마지막으로 클릭·키 입력·스크롤을 한 지 4초가 안 됐거나, 글자를 선택하고 있으면 기다려요. 그동안 목록의 해당 행이 깜빡여요.
- 저절로 옮겨지면 위쪽에 이유와 '← 돌아가기' 버튼이 잠깐 나와요.

## 할 수 있는 일

- **새 별 만들기**: 아래쪽 `✨ 새 별`(또는 `C`)로 새 프로젝트를 시작해요. 이름을 적으면 만들 곳을 미리 보여주고, 같은 이름의 폴더가 있으면 막아요. `별 만들기`를 누르면 순서대로 다음을 해요.
  1. 다른 프로젝트들이 모여 있는 폴더(보통 `~/orca/projects`)에 새 폴더를 만들어요.
  2. `git init`과 빈 `Initial commit`을 해요. git 사용자 설정이 없으면 커밋은 건너뛰어요.
  3. `orca repo add`로 Orca에 프로젝트를 넣어요.
  4. 고른 에이전트(Claude, Codex)를 `orca agent launch`로 그 안에서 터미널로 띄워요. `처음 할 일`을 적으면 첫 프롬프트로 같이 보내요. `셸만`을 고르면 빈 터미널을 열어요.

  **깃 주소에서 가져오기**: 이름 아래 칸에 깃 주소(`https://github.com/…`, `git@github.com:…`, `github.com/…`)를 넣으면 1, 2 대신 그 저장소를 같은 폴더에 `git clone`해요. 이름은 주소에서 저절로 채워지고 바꿀 수 있어요. 클론은 비밀번호를 묻지 않아서, 비공개 저장소는 이 맥에서 git 인증(키나 키체인)이 되어 있어야 해요. 깃허브가 거절하면(비공개 저장소는 권한이 없는 계정에 '없음'으로 답해요) `gh`에 로그인된 다른 계정으로 차례로 다시 받아 봐요. 실패하면 이유(주소 없음, 권한 없음, 연결 안 됨)를 알려줘요. 30분이 넘으면 멈춰요.

  **별이 모이는 동안**: 누르는 순간 화면이 그 별이 생길 자리로 날아가고, 거기에 가스 구름이 모여요. 먼지가 두 갈래 나선으로 빨려 들어가고, 일이 진행될수록 구름이 빠르게 돌며 좁아지고 가운데가 밝아져요. 구름 아래에는 지금 하는 일(자리 잡는 중, 가져오는 중 45%, Orca에 넣는 중, 터미널 여는 중)이 나와요. 터미널이 열리면 그 자리에서 별이 점화되고 구름이 걷혀요. 실패하면 구름이 흩어져요. 일은 서버에서 계속되니 창을 닫아도 되고, 다른 창에서도 같은 구름이 보여요. 에이전트를 띄우지 못하면 프로젝트는 남겨 두고 이유를 알려줘요.
- **새 행성**: 별을 고르면 오른쪽 리포트에 `🪐 새 행성` 버튼이 있어요. 그 프로젝트 폴더에서 Claude, Codex 또는 셸을 하나 더 띄워요. 별에 작업 폴더(브랜치)가 여럿이면 어디서 띄울지 고를 수 있고, 처음에는 보고 있던 행성의 폴더가 골라져 있어요. 새 터미널이 열리면 화면이 그 행성으로 가요. 서버는 지금 Orca에 터미널이 있는 폴더에서만 띄워요.
- **모든 세션을 한 화면에**: 터미널 화면이 1초마다 갱신돼요. Orca 창에 탭으로 열려 있지 않은 백그라운드 터미널도 보여요.
- **선택**: 에이전트가 띄운 메뉴의 선택지가 버튼으로 나와서 그 자리에서 바로 고를 수 있어요. `↑` `↓`로 고르고 `Enter`로 확정해도 돼요. 화살표로 고르는 동안에는 터미널에 아무것도 보내지 않고, `Enter`를 눌렀을 때 그 선택지 하나만 보내요. 같은 메뉴에 숫자가 두 번 가지 않게 화면이 바뀔 때까지 버튼이 잠겨요.
- **답장**: 카드 아래 입력칸에 쓰고 Enter를 누르면 그 세션에 보내져요. Shift+Enter는 줄바꿈이고, 한글 입력 중에 누른 Enter는 보내기로 처리하지 않아요.
- **직접 입력 선택지**: `Type something.` 같은 선택지를 고르면 입력칸이 메뉴 입력 모드로 바뀌어요. 그 상태에서 쓴 답은 메뉴 안의 입력칸으로 들어가요.
- **키 입력**: ⌨ 버튼을 누르면 ↑ ↓ Enter Esc Tab ⇧Tab ⌃C 같은 키패드가 열려요. 감지되지 않은 메뉴도 이 키로 다룰 수 있어요.
- **마지막 답변**: 큰 터미널 화면 옆에 마지막 요청, 마지막 답변, 지금 실행 중인 도구가 함께 나와요. 오른쪽 화면이 좁으면 문서 아이콘으로 화면과 답변을 번갈아 봐요. 격자 보기에서는 ⤢ 버튼으로 크게 열어요.
- **Orca에서 열기**: ↗ 버튼을 누르면 Orca 창이 그 터미널로 바로 이동해요.
- **필터·검색**: 상태별로 거를 수 있어요(전체, 확인 필요, 작업 중, 완료). 상태를 누르면 찾기처럼 동작해요: 찾기 칸이 `작업 중에서 찾기`로 바뀌고, Enter로 그 상태의 행성을 차례로 돌아요. 글자를 넣으면 그 안에서 찾고, 같은 상태를 한 번 더 누르면 전체로 돌아와요. 검색은 프로젝트 이름과 화면 내용, 답변을 모두 찾고, Enter로 찾은 세션으로 차례로 가요. `셸`을 켜면 에이전트 없이 셸만 열린 터미널도 보여요. 셸 표시와 카드 크기는 브라우저에 기억돼요.
- **빛과 소리 설정**: 위쪽 슬라이더 버튼이나 `S`로 열어요.
  - 빛: 빛 번짐(0~150%)과 밝기(50~130%). 처음에는 빛 번짐 10, 밝기 50으로 차분하게 시작해요. 더 화려하게 보고 싶으면 올려요.
  - 소리: 파도, 바람, 대나무 숲, 새, 풀벌레, 물방울, 음악, 풍경, 범종, 알림을 하나씩 켜고 끄고 크기를 따로 맞춰요. 슬라이더를 놓거나 다시 켜면 그 소리를 한 번 들려줘요. 꺼 둔 소리는 아예 만들지 않아요.
  - 장식: 은하 장식을 하나씩 켜고 꺼요. 지금은 마젤란 구름, 원시행성 원반, 초신성 잔해, 은하 중심 제트, 별의 왕관이 있어요. 아직 열리지 않은 장식은 🔒와 함께 열리는 조건이 보여요.
  - `처음대로`로 되돌려요. 모두 브라우저에 기억돼요.

상태 색: 주황은 선택·응답 필요, 빨강은 막힘, 파랑은 작업 중, 초록은 완료예요.

## 동작 방식

- `src/orca.mjs`: 읽기는 `orca` CLI가 쓰는 로컬 런타임 소켓에 바로 붙어요. 터미널 27개를 1초마다 읽어도 CPU를 1% 미만으로 써요. 소켓 프로토콜이 바뀌면 자동으로 `orca` CLI로 바꿔 읽어요. 보내기와 Orca에서 열기는 항상 `orca terminal send/switch`를 써요.
- `src/portal.mjs`: `worktree ps`(에이전트 상태)와 `terminal list`(터미널)를 합쳐요. 출력이 바뀐 터미널의 화면만 다시 읽어요. Orca가 주는 터미널의 에이전트 표시(`agentIdentity`)는 몇 초마다 잠깐씩 빠지곤 해서, 세션이 마지막으로 가졌던 에이전트를 30초 동안 붙잡아 둬요. 그래야 끝난 세션이 셸로 떨어졌다 돌아오며 완료 개수가 흔들리지 않아요. 백그라운드 작업만 지켜보는 에이전트(Orca의 monitoring 상태)는 Orca 사이드바처럼 작업 중이 아니라 대기로 보여요.
- `public/screen.js`: 화면 글자에서 선택 메뉴를 찾아요. Claude 권한 요청, 질문 메뉴, Codex 승인 메뉴를 알아봐요. 대화 속 번호 목록은 아래에 입력칸이 있으면 메뉴로 보지 않아요. Claude Code가 대화 옆에 패널(바뀐 파일, diff)을 열면, 여러 줄에서 같은 칸에 서 있는 `│`를 경계로 보고 왼쪽 대화만 읽어요. 줄바꿈된 질문은 한 문장으로 이어 붙여요.
- `electron/main.mjs`: Mac 앱. 서버를 앱 안에서 켜고(`server.mjs`의 `start()`), 제목 표시줄 없는 창에 페이지를 띄워요. `electron/preload.cjs`가 페이지에 Dock 배지와 알림만 열어 줘요.
- `src/projects.mjs`: 새 별과 새 행성 만들기. 폴더, git(또는 `git clone`), `orca repo add`, `orca agent launch`를 차례로 해요. 새 별은 요청에 바로 답하고 나머지는 뒤에서 하며, 단계와 클론 진행률(`git clone --progress`의 출력)을 `birth` 이벤트로 페이지에 알려요. 깃 주소는 https, ssh, git 꼴만 받고 `--`로 넘겨서, 옵션이나 로컬 경로, 명령을 실행하는 전송 방식은 들어갈 수 없어요. 방금 넣은 프로젝트를 Orca가 아직 못 찾으면(`selector_not_found`) 잠깐 기다렸다 다시 해요. 다른 실패는 에이전트가 이미 떴을 수 있어서 다시 하지 않아요.
- 브라우저 페이지는 Server-Sent Events로 바뀐 내용만 받아요.

## 성능

큰 모니터에서도 느려지지 않게, 은하는 최대 약 2560×1440 화소까지만 그려요. 그보다 큰 창에서는 조금 부드럽게 늘려서 보여줘요. 움직이는 장면에서 프레임이 계속 늦으면 해상도를 한 단계씩 낮추고, 여유가 생기면 다시 올려요. 아무것도 움직이지 않을 때는 초당 30번만 그려요.

## 보안

오러리는 터미널에 입력할 수 있어서, 명령 실행 권한과 같다고 봐야 해요. 그래서 다음처럼 막아 뒀어요.

- `127.0.0.1`에서만 열려요.
- Host 헤더를 검사해서 DNS 리바인딩을 막아요.
- 입력 요청에는 서버를 켤 때마다 새로 만드는 토큰과 같은 출처 검사가 필요해요. 다른 웹사이트는 이 토큰을 읽을 수 없어요.
- 키 입력은 정해 둔 키 이름만 받아요.
- 새 프로젝트 이름은 `/ \ : * ? " < > |`, 제어 문자, 점으로 시작하는 이름을 받지 않아서 정해진 폴더 밖으로 나갈 수 없어요. 이미 있는 폴더는 건드리지 않아요.
- 가져올 깃 주소는 `https://`, `http://`, `ssh://`, `git://`, `git@호스트:경로` 꼴만 받아요. `-`로 시작하는 값, 로컬 경로, `file://`, `ext::` 같은 명령 실행 전송은 막고, 주소는 `git clone -- 주소` 뒤에 넘겨요. 클론은 터미널 입력을 기다리지 않아요(`GIT_TERMINAL_PROMPT=0`, ssh는 `BatchMode`). 다른 깃허브 계정으로 다시 받을 때는 `gh auth token`의 토큰을 환경 변수로만 git에 넘겨서, 명령줄이나 받은 저장소의 설정에 남지 않아요.
